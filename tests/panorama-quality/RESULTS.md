## What each case proves

- **Ideal capture** (`clean`) — Baseline: every sweep starts on heading and tilts exactly +/-35 degrees.
  - FAIL: stitch took 63.4s, over 60.0s budget
- **Realistic sloppy capture** (`perturbed`) — Sweeps start off-heading, tilts are wrong, and every frame has hand shake.
  - FAIL: rmse 34.18 exceeds budget 34.0
- **Sloppy capture + motion data** (`perturbed-imu`) — Same capture with the phone's orientation samples available to the stitcher.
- **Tilted phone, no motion data** (`roll-control`) — Control for roll correction: +/-8 degrees of roll with nothing to correct it.
- **Tilted phone + motion data** (`roll-imu`) — Same roll, now correctable. Must beat roll-control.
  - FAIL: rmse 28.68 did not improve on roll-control (28.4)
- **Blown-out windows, single exposure** (`hdr-control`) — Control for bracketing: highlights clip to white with no companion still.
  - FAIL: stitch took 90.9s, over 60.0s budget
- **Blown-out windows + exposure bracket** (`hdr-fused`) — Same scene with the dark companion still, Mertens-fused. Must beat hdr-control.
  - FAIL: stitch took 116.2s, over 60.0s budget
- **Bare white walls, SIFT only** (`bare-walls-control`) — Control for learned matching: featureless walls starve SIFT, so the capture degrades or is rejected outright.
- **Bare white walls + learned matcher** (`bare-walls-learned`) — The same room with SuperPoint+LightGlue rescue. Must stitch cleanly where SIFT-only was rejected.
  - FAIL: stitch took 62.9s, over 60.0s budget
- **Unknown lens, measured from the photographs** (`lens-calibration`) — Phones rarely report a usable focal length and a 3:4 crop, a 16:9 crop and an ultrawide differ by tens of degrees. The capture is shot through a 59 degree lens and the stitcher is told nothing.
- **Plain room, uneven turns, SIFT only** (`plain-room`) — Regression guard for the retake loop: a bare-walled room turned unevenly, with no learned matcher available, must still return a panorama instead of demanding retakes the user cannot improve on.
  - FAIL: stitch took 124.8s, over 60.0s budget

Panorama images for every case are written to `output/` so the results can be
inspected visually, not only as numbers.
